## !1 feat(engine): structural zero-cost firewall (R1) - ACCEPTED
- Pure validation, no I/O; runs at the top of `run_task_with_sink` on primary + fallbacks. Good tests.
- **Important:** local/self-hosted models (Ollama, LM Studio, a relay) have no `:free` suffix and are
  blocked unless added via `FreeOnlyPolicy::with_extra_allowlist`, which `run_task_with_sink` never
  uses (it calls `FreeOnlyPolicy::default()`). Expose the extra allowlist through `RunOptions`/config.
- **Important:** the guarantee is about the model id string only; a gateway can still bill a `:free`-named
  route. The doc's "cannot bill you. Ever." is stronger than the code proves - soften or add a
  `usage.cost` runtime check.
- Nit: `is_free_model` / `validate_model` duplicate `FreeOnlyPolicy::is_allowed` / `validate`.
- Nit: docs reference `docs/zero-telemetry.md` (R14), which does not exist yet.
- CLI note: a free-only policy is product policy; fine in Desktop, but the hook point (validating the
  model chain before each attempt) belongs in zen-agent's ModelChain upstream.

## !5 R3 ask-first scope guard - ACCEPTED
- Opt-in; read-only tools pass; `scope.js` escapes all interpolated text (no XSS).
- **Important (security):** Bash checking is a token heuristic and is easy to bypass (`python -c`,
  `cd .. && …`, `$HOME/x`, `find -delete`, backticks). Treat it as a guard-rail, not a sandbox; the doc
  should say so. Real enforcement is the deferred OS sandbox (PLAN step e).
- **Important (Windows/macOS):** paths are normalised lexically, not canonicalised: symlinks escape
  the root; macOS `/tmp` vs `/private/tmp` and Windows case-insensitivity / `\\?\` prefixes make
  `starts_with(root)` give false denials or false allows. Canonicalise `root` once and compare
  case-insensitively on Windows.
- Nit: `DESTRUCTIVE_PATTERNS` substring match (`"sudo "`, `"dd if="`) will false-positive on harmless
  text such as `echo "pseudo code"`.
